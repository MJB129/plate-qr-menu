<objective>
## Goal
Gate the three page action handlers in `new/page.tsx` (create, addcat, additem) against plan limits, and replace the "New Menu" button on the menus list with an upgrade prompt when the user is at their menu limit.

## Purpose
02-01 secured the API routes. This plan secures the server-component action handlers that bypass those routes — without this, a free user can still create menus by submitting the in-page form directly. It also surfaces the limit visually so users understand why their action is blocked.

## Output
- `new/page.tsx` — three action handlers gated
- `menus/page.tsx` — "New Menu" button replaced with upgrade prompt at limit
</objective>
