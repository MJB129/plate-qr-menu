<objective>
## Goal
Enforce plan tier limits at the API layer — free users are blocked from creating more than 1 menu, 3 categories/menu, or 10 items total, with a 403 (JSON) or redirect-with-error (form) response.

## Purpose
Without API-layer enforcement, plan limits are UI-only and trivially bypassed. This plan establishes the security boundary before billing is added in Phase 3 — a free user must not be able to exceed their tier by calling the API directly.

## Output
- `src/lib/plan-limits.ts` — plan constants and three check functions
- Three API routes modified to call limit checks before INSERT
</objective>

<acceptance_criteria>

## AC-1: Menu creation blocked at plan limit
```gherkin
Given a free user who already has 1 menu
When they POST to /api/menus (JSON or form)
Then the response is 403 JSON { error, code: 'PLAN_LIMIT' } or redirect with ?error=Plan+limit+reached
And no menu is inserted
```

## AC-2: Category creation blocked at plan limit
```gherkin
Given a free user whose menu already has 3 categories
When they POST to /api/menus/[id]/categories/add
Then they are redirected with ?error=Plan+limit+reached
And no category is inserted
```

## AC-3: Item creation blocked at plan limit
```gherkin
Given a free user who already has 10 items total across all their menus
When they POST to /api/categories/[id]/items/add
Then they are redirected with ?error=Plan+limit+reached
And no item is inserted
```

## AC-4: Paid users are not limited
```gherkin
Given a user with plan = 'starter', 'pro', or 'enterprise'
When they create menus, categories, or items beyond free-tier limits
Then the request succeeds (limits are Infinity for paid tiers)
```

    `checkMenuLimit(userId: string, plan: string): Promise<LimitCheck>`

    - If limit is Infinity → return { allowed: true, limit: Infinity, current: 0, resource: 'menus' }
    - Query: `SELECT COUNT(*) as n FROM menus WHERE user_id = ?`
    - Return { allowed: count < limit, limit, current: count, resource: 'menus' }

    `checkCategoryLimit(menuId: string, plan: string): Promise<LimitCheck>`

    - Query: `SELECT COUNT(*) as n FROM menu_categories WHERE menu_id = ?`

    - If itemsTotal is Infinity → return allowed: true early
    - Query: `SELECT COUNT(*) as n FROM menu_items i JOIN menu_categories c ON i.category_id = c.id JOIN menus m ON c.menu_id = m.id WHERE m.user_id = ?`
    - Return { allowed: count < limit, limit, current: count, resource: 'items' }
